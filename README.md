# nvim-setup

- Simple Neovim setup.
- Blazing fast and highly customizable.
- Many useful features and plugins.
- Language server protocol.
- Completion.
- Format.
- Lint.
- etc.

## Requirements

### Mandatory

- NVIM release v0.12.4
- Nerd font
- git
- C compiler (for building parsers)
- curl
- tree-sitter
- lua-language-server
- ripgrep (for fzf-lua)
- fzf (for fzf-lua)
- fd (for fzf-lua)

### Optional

- npm
- pip

## Clone

```bash
git clone https://github.com/X3ru4/nvim-setup.git ~/.config/nvim
```
