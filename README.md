# Neovim

- Simple Neovim setup.
- Blazing fast and highly customizable.
- Many useful features and plugins.
- Language server protocol.
- Completion.
- Format.
- Lint.
- etc.

## Requirements

- [Nerd font](https://www.nerdfonts.com/font-downloads)
- clang (For building parsers)
- lua-language-server (Easy to configure)
- treesitter
- rust (Need to build blink.cmp)
- python (Optional)
- nodejs (Optional)
- ripgrep (For fzf-lua)
- fzf (For fzf-lua)
- fd (For fzf-lua)
- git

## Clone

```bash
git clone https://github.com/X3ru4/nvim-setup.git ~/.config/nvim
```
